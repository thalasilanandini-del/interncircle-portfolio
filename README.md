# Personal Developer Portfolio

A responsive personal developer portfolio website created as part of my
InternCircle Web Development Internship.

## About the Project

This portfolio website showcases my introduction, technical skills,
projects and professional social links.

The website is designed to provide a clean and responsive experience
across desktop, tablet and mobile devices.

## Features

- Responsive personal portfolio
- Semantic HTML5 structure
- Responsive navigation
- About Me section
- Technical Skills section
- Projects section
- Contact and social links
- Mobile-friendly design
- CSS Flexbox and Grid layouts
- Hover effects and smooth scrolling

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Media Queries
